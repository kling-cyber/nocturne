NOCTURNE 4.3.0 includes:
- Multiplayer role authority and randomized non-Killer investigator specialties
- Immediate server-side role-action results with optional AI refinement
- Separate Evidence and Case Feed records for role actions
- Private human role information in multiplayer public state
- Server validation for role targets and critical-window actions
- Direct on-demand local ComfyUI visual generation
- Realistic Vision V5.1 FP16 visual workflow support
- 768x512, 20-step, CFG 8, Euler/Simple local image generation
- Fixed 10-second local image-generation timeout
- No per-player visual request cooldown
- Same-source visual generation concurrency protection
- Frontend runtime guards for role rendering and visual requests
- Interactive Three.js 3D experience layer
- Procedural 3D spatial map generated from live case locations
- Live player and NPC location markers
- Interactive location focus and CCTV markers
- Cinematic map controls with reduced-motion support
- Repository-wide Node syntax checking in GitHub Actions

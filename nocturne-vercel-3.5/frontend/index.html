TECHNOLOGY

LIVE ARCHITECTURE

Browser-based frontend connected to a persistent Node.js / Socket.IO game server.

Multiplayer supports 2–8 human players. Single player places one human investigator inside the same simulation engine with autonomous NPC characters.

SINGLE PLAYER

AUTONOMOUS KILLER

In solo mode the Killer is an AI-controlled NPC with a private motive, memories, pressure, relationships, suspicion and self-preservation.

The player remains the investigator. The hidden truth stays authoritative on the server.

CASE PHILOSOPHY

NO FIXED SCRIPT

Cases are generated from a living simulation. Characters can move, remember, cooperate, lie, deflect, panic, investigate and change their behavior as the case develops.
